# まなびドラゴン（ブラウザゲーム）

`index.html` をダブルクリックするだけで遊べます（サーバー不要・オフラインOK）。

## ゲームの流れ
- 1日目＝月曜。月〜金：教科レッスン（1日1問）。正解で能力+500〜800、不正解でも+150〜250（最大9999）
- 土：スキルを3つから1つ選ぶ ／ 日：ボス戦（7・14・21日目）→ 22日目「ファイナルデー」にラスボス。ボス戦後は全回復
- 間違えた問題は「苦手リスト」へ。ボス戦で正解すると「苦手こくふく」で、最初に正解した場合との差（+450）が能力に加わる
- セーブなし・スコアアタック

## ボスの行動（毎ターン「次のこうどう」を予告）
| 行動 | 内容 | 対策 |
|---|---|---|
| こうげき／3回れんぞく | 通常ダメージ | 間違えると1.3倍くらう |
| 身を守る | こちらの攻撃がほぼ効かない | 保健で回復のチャンス |
| 力をためる→ため攻撃 | 次のターンに3倍ダメージ | ためているときに「ばつぐん」で当てるとひるむ／保健ガードで半減 |
| おたけび | 攻撃力アップ（重なる） | 早めに倒す |
| 回復 | ボスが最大HPの8%回復 | ― |
| 8秒以内に答えろ | 制限時間つき問題＋攻撃 | 時間切れは不正解 |
| カウントダウン | 3ターン後に最大HPの9割ダメージ | 期限内に一定ダメージで「ブレイク」→次ターンダメージ2倍 |
| 属性チェンジ | ラスボスが属性を変える | 予告を見て教科を切りかえ |

ステージ：1面＝基本だけ／2面＋連続・おたけび／3面＋カウントダウン・時間制限・回復／ラスボス＝全部＋属性チェンジ、一度たおすと第2形態（堕天使）として全回復で復活
バランス調整は `game.js` 冒頭の `STAGES`（HP・攻撃力・行動の順番）で。

### Stable Diffusion プロンプト例
- 自キャラ：`cute chibi baby dragon, big eyes, (red scroll and brush motif:1.2), game character, full body, facing right, simple background` → 段階が上がるほど `young dragon, armor, glowing aura, majestic` を足す
- ボス：`giant centipede made of scrolls and kanji, rpg boss monster, cute but menacing, full body, facing left, simple background`
- 背景：`fantasy grassland battlefield, anime background, no people, vertical composition` → `ruined, dusk` → `dark ruins, purple sky` → `volcano, lava, red sky`

## 問題の差し替え
- CSV：タイトル画面の「問題CSVを読みこむ」（Excel保存のShift-JISもOK。ブラウザを閉じると元に戻る）
- 常に使う問題：`questions.js` を書き換え

## ハードモード
- 4〜6年の全問題から出題。与ダメ×0.62・被ダメ×1.5・ボスHP×1.2・スコア×1.5（game.js の `HARD`）
- 四天王・ワスレーヌの行動が強化：吸収こうげき（absorb）、保健封印（seal）が追加（game.js の `HARD_PAT`）
- ワスレーヌ第2形態を倒すと、夜明けの背景で裏ボス「剣聖クロガネ」との最後の試練（game.js の `KUROGANE`）
  - 奥義・一閃（今のHPの9割）、ため攻撃、2ターンのカウントダウン大技など
  - 負けてもクリア扱い（世界は救済済み）。勝つと「完全勝利」＋50,000点
  - 画像：images/boss/kurogane.png ／ セリフ：assets.js の story.trial と lines.kurogane

## 1日1回・遊べる時間・セーブ（ブラウザの中に保存）
- 挑戦は1日1回（どのモードでも1回はじめたらその日は終わり。挑戦権はためられない）
- 遊べるのは8時〜20時だけ（それ以外は「竜はねむっている…」）。プレイ中に20時をすぎると、次の区切りで自動で中断
- 「⏸ 中断」で進行状況を保存（タイマーも止まる）。タイトルの「つづきから」で再開。再開は挑戦権を使わない
- 自動セーブ：毎日の始まり・教科えらび・バトルのコマンドえらび・問題を出した時点。とちゅうで閉じても同じ問題から再開
- コンティニューあり：最終スコア×0.5・ランクはCまで・パスワードなし
- タイトルの「📜 冒険の記録」で、モードごとのハイスコア（結果画面ごと）と前回の記録を見られる（問題CSV読みこみボタンは廃止）
- 設定は game.js の `PLAY_HOURS`・`CONT_SCORE`・`CONT_RANK_MAX`。保存はブラウザの localStorage（閲覧データを消すとリセット）

## パスワードロック
- ハード・エクストリームは最初ロック（グレー）。タイトルの「🔑 パスワード」でダイヤル式に3けたを入力
- 4〜6年をクリア → リザルトに **961（くろい）** ＝ハード解除／ハードをクリア → **621（むずい）** ＝エクストリーム解除（ハードも解除）
- ページを開き直すとロックにもどる。パスワードは game.js の `PASSWORD`

## エクストリーム
- タイトルの「💀 エクストリーム」。4〜6年の全問題・与ダメ×0.6・被ダメ×1.6・ボスHP×1.3・スコア×2（game.js の `EXTREME`）
- クロガネ戦はなし。ワスレーヌ第2形態のあと、ブラックアウト→真っ白な世界で第3形態「無垢なるワスレーヌ」（images/boss/last3.png、game.js の `LAST3`）
  - 毎ターン属性がランダムに変わる＋ランダムで教科を2ターン封印（同時に2つまで）。法衣で9999を超えている前提の強さ

## アイテムとイベント
- レアリティ：ノーマル★ `SKILLS`／レア★★ `SKILLS_HARD`／激レア★★★ `SKILLS_SR`／レジェンド☆ `SKILLS_LR`。出現率は game.js の `DROP_RATE`（難易度×場面ごとの%）。アイテムに `r: 1〜4` を付けると星とカード枠の色（白・青・金・虹）が変わる
- アイテムは最大6個。7個目を入手したら、捨てるアイテムを選ぶ（game.js の `MAX_ITEMS`）
- 紋章（ハードは聖紋章）はステータスに倍率がかかる（重ねがけOK・最大9999）。手放すと元の数値にもどる
- 水曜日のランダムイベント：拾った！(30%)／師匠のおくりもの(30%)／くじびき(30%)／悪魔のささやき(10%)
- ボスはHPが半分以下になると固有のピンチセリフを言う（assets.js の lines の pinch）
- エンディングで師匠がほめる（assets.js の story.ending）

## バランス調整用の数値（game.js 上部）
- `EMBLEM`：紋章1個あたりのステータス倍率（通常1.25・ハード聖紋章1.35）
- `HP_UP`：保健レッスンで増える最大HP（正解300・不正解120）
- `DMG_MUL`：与ダメージの基本倍率
- 進化：assets.js の `sumTier`（最終進化の合計値）・`ultTier`（究極形態の合計値）
- 出題：教科ごとに山札方式。全問を一巡するまで同じ問題は出ない（間違えた問題はボス戦で40%の確率で再出題）
